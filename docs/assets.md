## 4. Optimization Strategy
- **Format**: All assets converted to modern WebP / AVIF with high-quality fallback.
- **Master Downscaling**: Downscaling 16MB raw Wix uploads (e.g. `ec3202_d207708ebdb647cfbeb6fb23696d0e5b`, originally 16.6MB) to responsive variants (320px, 640px, 1200px, 1920px).
- **Responsive `next/image`**: Native responsive sizes, lazy loading for below-the-fold assets, and priority loading for LCP hero elements.
